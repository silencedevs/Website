## Features

- **Strength training** controls
- **Rebirth** controls
- A separate **boss farming** interface
- **Pet management**
- **Teleports**
- **Saved configurations**

## Compatibility

Game updates can affect script compatibility. Check the [Silence Discord server](https://discord.gg/9eFf93Kg8D) for current support.
